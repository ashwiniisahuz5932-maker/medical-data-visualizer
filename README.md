🩺 Medical Data Visualizer

A complete Data Analysis and Visualization project built with Python, Pandas, Matplotlib, and Seaborn. This project analyzes medical examination data to discover patterns related to cardiovascular disease, lifestyle habits, and body health metrics.

---

📌 Project Overview

The Medical Data Visualizer project focuses on cleaning, processing, and visualizing medical dataset information to identify relationships between patient health indicators and cardiovascular disease.

The project includes:

- Data cleaning
- Feature engineering
- BMI-based overweight detection
- Correlation analysis
- Categorical data visualization
- Heatmap generation

---

🚀 Technologies Used

⚙️ Features Implemented

✅ Overweight Classification

Calculated BMI using height and weight data to determine whether a patient is overweight.

✅ Data Normalization

Normalized:

- Cholesterol levels
- Glucose levels

to improve analysis consistency.

✅ Categorical Plot

Generated comparative visualizations for:

- Cholesterol
- Glucose
- Smoking habits
- Alcohol consumption
- Physical activity
- Overweight status

based on cardiovascular disease presence.

✅ Correlation Heatmap

Created a heatmap to visualize relationships between medical attributes and detect strong correlations.
